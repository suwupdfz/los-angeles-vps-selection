## 512MB 内存能干什么，不能干什么

512MB 内存加 10GB NVMe，能跑的东西很有限：SSH 隧道、轻量代理、监控探针、定时脚本、单个小体积的常驻进程。装个面板再塞数据库，内存很快就满了，swap 一开，NVMe 的寿命和响应都受影响。

## 常见问题

**流量跑完会停机吗？**
不会。限速到 3Mbps，下个月按账单周期恢复。3Mbps 够 SSH 和轻量代理，不够推流。

**只能月付吗？**
页面上五档都只标了 Monthly，没有季付、半年付、年付的选项。

**512MB 能装宝塔吗？**
能装，但装完之后跑不动。面板本身就要占一两百 MB，再起 MySQL 和 PHP，内存立刻见底。要面板就上 4核6G 那档。

**双 ISP 是每档都有吗？**
页面顶部写“全场双isp ip”，但第一档的规格里只标了 IPv4×1。想确保拿到双 ISP，选明确标注的那几档。

**这些机器能做网站吗？**
技术上可以，配置上不合适。10GB 硬盘加 512MB 内存，放个静态页勉强，动态站点会很难受。
